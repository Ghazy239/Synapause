# Synapause Changelog

## v1.1.2 Stroop update

### Features
- Added real Stroop Test visualization.
- Words are now displayed using dynamic ink colors instead of plain text.
- Added dedicated Stroop word element in the quiz overlay.
- Automatic UI switching based on question category (Stroop, Visual, Numeric).

### Improved
- Improved Stroop question layout.
- Better spacing and typography for quiz questions.
- Minor overlay visual polish.
- Simplified website monitoring synchronization.
- Website monitoring settings now synchronize automatically without requiring users to toggle checkboxes after startup.
- Removed unnecessary storage dependency in the extension background process.

### Fixed
- Fixed monitored websites not being initialized correctly after startup.
- Fixed category rendering issues in the quiz overlay.
- Improved quiz state synchronization reliability.

### Notes
- new features were introduced in this release.
- This is a maintenance release focused on stability and bug fixes.
